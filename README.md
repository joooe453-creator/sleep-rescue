# 睡眠救援大作戰

人工智慧方法與工具期末專題 ｜ SDG 3 健康與福祉

基於 Kaggle [Sleep Health and Lifestyle Dataset](https://www.kaggle.com/datasets/uom190346a/sleep-health-and-lifestyle-dataset)（374 筆）設計的 7 天決策互動遊戲，玩家扮演大學生，每天從 8 種活動中分配 240 分鐘，看 7 天累積下來能否成為「睡眠管理高手」。

## 線上遊玩

https://joooe453-creator.github.io/sleep-rescue/

## 玩法

- 連續 7 天，每天面對不同情境（期中考、社團聚會、深夜趕報告 …）
- 從 8 種活動中選擇：讀書、咖啡、運動、滑手機、冥想、提早就寢、朋友聚餐、打電動
- 每個選擇影響 5 項指標：😴 睡眠、⚡ 精神、😰 壓力、❤️ 健康、😊 心情
- 第 7 天結束後，依綜合分數獲得 A / B / C / D 評等與個人化建議
